# Movie Ticket Booking System

A console-based Movie Ticket Booking System developed in C language.

## Features
- Multiple movie selection
- Different show timings
- Seat booking and cancellation
- Multiple seat booking
- Theatre-style seating display
- Menu-driven program

## Concepts Used
- Structures
- Arrays
- Functions
- Loops
- Conditional Statements

## How to Run

Compile:
gcc Pro1.c -o Pro1

Run:
.\Pro1.exe
